# 마키보 코드 3분 요약 — 턴과 스킬의 큰 흐름

기준: 2026-10-02 현재 작업 트리 · **검토 대기**. 기존 [상세 해설](README.md)은 2026-10-01 커밋 `f69ceba` 기준이다. 그 뒤 일반 스킬 코드가 추가되어, 아래 설명은 현재 작업 트리의 흐름을 반영한다.

## 한 문장으로

**화면의 버튼 → `TurnSandboxController` → `TurnBattle` → 화면 갱신** 순서로 움직인다. 화면은 입력과 표시를 담당하고, 전투 규칙과 상태 변경은 `Core`가 담당한다.

## 중요한 파일만 다섯 묶음

- `BattleRoster.cs`: 유닛의 기본 능력치·편성, 전투 중 위치·HP·BP를 보관한다. 기본 정보와 변하는 상태를 구분한다.
- `MainSkill.cs`: 스킬 정의와 피해 계산 방법을 담는다. `TurnBattle.Skills.cs`는 스킬 예약, COST 확보, 실행 시 재검사와 HP/BP 변경을 맡는다.
- `TurnBattle.cs`: 5단계 턴, Speed 순서, 예약 확정, 유닛별 차례, 전체 턴 번호를 관리한다.
- `TurnSandboxController.cs`: 버튼 입력을 Core 함수로 전달하고 `턴 넘기기`를 자동 진행한다. 지금은 A/B/X/Y 같은 임시 편성도 여기서 만든다.
- `StageBattleView.cs`·`MainSkillPanel.cs`: 기존 `InGame`의 9슬롯·버튼·COST 바를 표시하고, 아군·스킬·대상 선택 창을 제공한다. `TurnSandboxView.cs`는 같은 로직을 확인하는 독립 화면이다.

## Play부터 다음 턴까지

1. Unity가 `Makibo Battle`의 `TurnSandboxController.Awake()`를 호출한다. 컨트롤러는 화면과 스킬 선택 창을 만들고 `ResetBattle()`로 전투를 시작한다.
2. Core가 **턴 시작 → 초기화 → 행동 순서 → 예약 → 실행** 단계를 따른다. 첫 화면은 1턴 예약 단계이며 양측 COST는 3이다. 필드 유닛의 Speed 순서는 기본 예제에서 **A → X → B → Y**다.
3. 예약 단계에서 아군은 스킬과 적 대상을 고르거나 턴 종료만 예약한다. `예약 적용` 전의 선택은 실행 예약이 아니다. 적은 현재 턴 종료만 자동 예약한다.
4. `예약 확정` 뒤에는 예약을 바꾸지 못한다. 실행 단계에서 유닛의 차례를 시작하고, 스킬 예약이 있으면 **다음 진행에서 스킬**, 그다음 진행에서 **턴 종료**를 처리한다. 스킬이 없으면 차례 시작 뒤 곧바로 턴 종료다.
5. `턴 넘기기`는 남은 진행을 반복해 **다음 턴의 예약 단계**까지 이동한다. 마지막 유닛의 차례가 끝나야 턴 번호가 오른다. 2턴 초기화에서는 필드 인원만큼 COST를 얻어, 기본 예제의 양측 COST가 **3 → 5**가 된다.

## 버튼을 누르면 실제로 일어나는 일

- **메인 스킬:** 선택 창에서 아군 → 스킬 → 적을 고르고 `예약 적용`을 누르면 `ReserveMainSkill()`이 예약을 저장한다. COST는 이때 *확보*하며 실제 소비는 실행 결과에 따른다.
- **다음 단계 / 행동:** `Step()`이 Core를 한 번만 진행한다. 예를 들어 A의 차례 시작과 A의 스킬 실행은 서로 다른 클릭이다.
- **턴 넘기기:** `SkipTurn()`이 코루틴을 시작해 다음 턴 예약 단계까지 자동 진행한다. 이미 넣은 스킬 예약은 유지하고, 필요한 턴 종료 예약만 채운다.
- **처음부터:** `ResetBattle()`이 진행 중인 자동 처리를 멈추고 임시 유닛·HP·BP·COST·턴 번호를 초기 상태로 되돌린다.

예를 들어 아군 A의 **기본 사격**을 적 X에게 예약해 적중하면 X의 HP가 **100 → 70**, A의 해당 스킬 BP가 **5 → 4**가 된다. 이 시점에는 A의 차례가 아직 열려 있고, 다음 진행에서 턴 종료가 처리된다. 대상이 사라지거나 조건이 바뀌면 실행 직전에 다시 검사한다.

## 현재 범위

스킬은 기능 확인용 임시 데이터이며 적의 스킬 선택 AI는 없다. 일반 공격은 단일 적 대상·단발 공격을 지원한다. 확정 시와 실행 시 모두 원래 스킬 BP가 0이면 **헤일로 이상**으로 대체되는 경로도 있다. 이동·교체·EX·아이템·공격 애니메이션과 전체 게임 진입 흐름은 아직 연결되지 않았다.

**읽을 출발점:** 턴 자체는 `TurnBattle.cs`의 `Advance()`와 `AdvanceExecution()`, 버튼 연결은 `TurnSandboxController.cs`의 `Awake()`·`Step()`·`SkipTurn()`, 스킬 흐름은 `TurnBattle.Skills.cs`의 `ReserveMainSkill()`·`ExecuteMainSkill()`을 보면 된다. 세부 값·예외는 [현재 스킬 검토 기록](../reviews/2026-10-02-main-skills.md)과 [기존 상세 해설](README.md)에서 찾을 수 있다.
