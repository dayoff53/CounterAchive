# 확정 결정과 미정 사항

기준일: 2026-09-30. 원문 근거의 행 번호는 [보존본](reference/battle-rules-2026-09-23.txt) 기준이다.

`확정`은 dayoff53의 명시적 결정 또는 제공된 규칙이다. `미정`은 원문이 결정을 남긴 사항, `검토 후보`는 구현을 위해 Codex가 발견한 명세 공백이다. 검토 후보가 새로운 게임 규칙을 뜻하지 않는다.

## 확정된 프로젝트 결정

| ID | 날짜 | 결정 | 근거 |
| --- | --- | --- | --- |
| D-001 | 2026-09-29 | 프로젝트 이름 마세이 키보토스, 약칭 마키보. 기존 CounterAchive를 전환해 게임 완성 | dayoff53의 이번 환경 구성 요청 및 규칙 원문 |
| D-002 | 2026-09-29 | 기능 구축은 Codex가 주도하고 dayoff53이 결과를 검토 | dayoff53의 이번 환경 구성 요청 |
| D-003 | 2026-09-29 | 제공된 2026-09-23 전투 규칙을 전환의 기준으로 보존 | dayoff53의 이번 환경 구성 요청 |
| D-004 | 2026-09-30 | 기존 카운터 아카이브의 약칭은 카브 | dayoff53의 명시적 명칭 결정 |
| D-005 | 2026-09-30 | 새 마키보와 기능이 겹치거나 불필요한 카브 스크립트는 Assets 외부에 격리하고 새로 작성. 강한 의존 코드도 함께 폐기 가능 | dayoff53의 전투 구현 밑작업 요청. 영향: 구형 전투·데이터·저장·편성·진행 연결. [결과/검증](reviews/2026-09-30-carve-quarantine.md) |
| D-006 | 2026-09-30 | 스크립트 외 리소스는 보존. 폐기가 필요하다고 판단해 실행하는 예외는 이유를 보고 | dayoff53의 리소스 보존 지시. 이번 격리에서 리소스 폐기 없음 |

원문 이후 새로 확정한 **전투 규칙 변경은 아직 없다.** 문서 분리/로직과 연출 분리 권장은 Codex의 개발 구성 선택이며 별도 게임 규칙이 아니다.

## 원문이 명시한 미정 사항

| ID | 항목 | 근거 | 결정이 필요한 시점 |
| --- | --- | --- | --- |
| Q-001 | 헤일로 이상의 HP 소모·범위 피해·자체 BP 회복 적용 순서와 명중 실패 시 부가 효과 | 11절 1102–1104행 | 헤일로 이상 실행 처리 |
| Q-002 | 원래 대상 소멸/사거리 이탈과 BP 부족이 겹칠 때 대체 스킬과 대상 검사 우선순위 | 11절 1106행 | 스킬 실행 검증/대체 |
| Q-003 | 배치·교체 후 기존 유닛 지정의 승계 범위 | 13절 1220행 | 교체/타깃 연결 |
| Q-004 | 대기로 복귀한 유닛의 남은 예약 정리와 턴 종료/횟수형 감소 시점 | 14절 1444행 | 교체/상태 처리 |
| Q-005 | 이미 확정한 예외 외 다단 공격의 상세 처리 | 2절 209행, 11절 982행 | 개별 다단/반격 구현 |
| Q-006 | 개별 일반 스킬 최대 BP, 요괴 MAX 이외 아이템 회복량 | 11절 1108행, 20절 1690–1694행 | 실제 콘텐츠 데이터 작성 |

원문 1444행은 Q-004가 20절에 있다고 안내하지만 실제 20절에는 해당 결정이 없다. 누락된 참조를 확정 규칙으로 보충하지 않고 여기에 미정으로 유지한다. 이 항목들은 전체 프로젝트를 멈추게 하는 사전 승인 목록이 아니며, 해당 결과에 영향을 주는 작업에서 필요한 결정을 다룬다.

## 이후 결정을 남기는 방법

새 결정에는 `ID / 날짜 / 상태 / 결정자 / 관련 원문 절 또는 Q·C ID / 확정 내용 / 이유 / 영향 파일·테스트`를 적는다. dayoff53의 결정이 오면 관련 미정의 해결 근거를 연결하고, 원문 스냅샷은 보존하면서 규칙 요약·구현·검증 사례를 갱신한다. 검토 후보나 임시 구현을 이유 없이 `확정`으로 바꾸지 않는다.
