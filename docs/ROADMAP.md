# 전환 계획과 진행 상태

기준일: 2026-10-02. 아래 구현 순서는 Codex의 제안이며, 게임 규칙의 추가 확정이 아니다.

## 현재 위치

- 2026-10-04 정리: 사용자 요청으로 씬/프리팹의 Missing Script 컴포넌트 167개 제거, 231개 에셋 재검사에서 0개. 사본 컴파일·PlayMode 11개 통과, **검토 대기**. 리소스/정상 컴포넌트 보존과 잔여 콘솔 경고는 [검토 기록](reviews/2026-10-04-missing-script-cleanup.md) 참조.

- 2026-10-04 슬롯/HP UI: 기존 바닥 스프라이트와 HP 바를 `Stage_Battle` HUD에 재사용. 이동·피해·퇴각·초기화 연동, 사본 컴파일·PlayMode 11개 통과, **검토 대기**. [검토 기록](reviews/2026-10-04-unit-slot-hp-ui.md).

- 2026-10-04 UI 후속: 기존 SkillSlot 프리팹으로 스킬 데이터·BP·타입/속성 색상을 표시한다. 컴파일·EditMode 67개/PlayMode 10개 통과, **검토 대기**. [검토 기록](reviews/2026-10-04-skill-slot.md).

- 2026-10-04 후속: 이동 금지 중 재시도는 디버프를 갱신하지 않도록 D-009 적용. 컴파일·EditMode 67개/PlayMode 8개 통과, **검토 대기**. [변경 기록](reviews/2026-10-04-movement-lock-retry.md).

- 프로젝트 방향: CounterAchive → **마세이 키보토스** 전환.
- 구현한 작업: 개발 문맥 구성, 카브 코드 격리, 새 턴 기반, Stage_Battle의 InGame 리소스 연결, 일반 단일 공격 예약/실행, 서브 이동과 예약 미리보기. 기존 프리팹/스프라이트는 보존.
- 현재 제출 상태: **서브 이동과 미리보기 검토 대기**. 사본에서 컴파일, EditMode 63개/PlayMode 6개 통과. [작업·검증 기록](reviews/2026-10-02-movement.md). 헤일로 순서는 D-007, 이동 예시 표시는 D-008로 기록했으며 구현 검토 완료를 의미하지 않음.
- 새 전투 구현: 2세력 PvE에서 이동·일반 스킬과 마지막 턴 종료를 예약한다. HP/BP/명중/사거리/COST/속성 피해를 연결했다. 변화·일반 광역·다단·일반 상태·교체와 적 스킬/이동 AI는 미구현. Stage_Battle 외 카브 진행 흐름은 연결하지 않았다.
- 다음 작업: 이번 이동 미리보기와 실행 화면을 검토한 뒤 다음 행동을 추가한다. 변화/일반 광역/다단/아이템 등의 범위는 별도 기능 단위로 확장한다.

## 다음 구현에서 확인할 사항

- 카브 AP 누적 로직은 Assets 외부로 격리했다. 새 Speed 전투는 별도 네임스페이스와 어셈블리로 작성하고 구형 코드에 의존하지 않는다.
- 새 전투용 씬에서 시작한다. 카브 씬·프리팹의 Missing Script를 일괄 제거하거나 구형 코드를 복원해 숨기지 않는다. 리소스 재사용 시 필요한 시각 요소를 가져와 새 코드로 연결한다.
- 씬 연결을 바꾸기 전에 기존 사용자 작업과 `Stage_DD_Battle_2.0`의 의도를 해당 파일에서 확인한다.
- [미정 항목](DECISIONS.md) 중 교체 후 예약 정리와 대상 승계는 관련 기능 구현 시 해소한다. 헤일로 이상 처리 순서는 D-007로 확정했다.
- 첫 테스트 범위 후보: 첫 턴 COST, 필드 수/배치 제한, Speed 순서와 현재 행동권 유지, 실패 후 다음 예약, 공격·필수 후속 효과 뒤 종료.

## 상태 갱신 기준

- **구현 전**: 해당 작업 단위에 착수하기 전. 기존 코드가 전혀 없다는 뜻은 아니다.
- **진행 중**: 구현 또는 필수 검증을 수행 중.
- **검토 대기**: 결과·검증 수준·재현 절차를 dayoff53에게 제출한 상태.
- **검토 완료**: dayoff53의 확인/피드백을 받은 뒤 기록한 상태.

테스트 통과 여부는 상태 이름에 숨기지 말고 검토 기록에 별도로 남긴다. 후속 작업에서는 관련 행과 현재 위치를 갱신하고, 오래된 제안을 확정 요구사항처럼 취급하지 않는다.
