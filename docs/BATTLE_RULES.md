## 전투 상태와 턴

- 가로 **9슬롯**. 플레이어별 편성 최대 **6명**, 필드 최대 **3명**, 시작은 편성 앞의 **2명**. 시작/추가 출전은 스테이지별 출전 구역을 지킨다.
- 필드·대기·퇴각을 구분한다. 대기 복귀는 퇴각이 아니며 HP/상태를 보존한다. 퇴각 유닛은 출전 불가다.
- 능력치는 `Hp / TAtk / MAtk / TDef / MDef / Speed`다. Speed와 두 방어력의 최솟값은 0. 명중률은 스킬별로 정한다.
- 초기 COST는 **3**, 상한 **10**. 첫 턴에는 COST 획득만 생략한다.
- 모든 세력의 필드 유닛이 Speed 내림차순으로 기본 차례를 한 번씩 가진다. 같은 Speed는 균등 추첨하고 다음 턴에 이전 결과를 재사용하지 않는다. 행동 순서는 공통 공개 정보다.
- 기존 AP/AV 누적 방식이나 행동권 이월로 구현하지 않는다.

| 단계 | 처리 순서 |
| --- | --- |
| 1. 턴 시작 | 현재 필드 기준 승패 확인 |
| 2. 턴 초기화 | 상태 효과 적용(지속 피해는 동시 적용) → 턴형 지속 시간 감소 → 스킬 쿨다운 감소 → 현재 아군 필드 수만큼 플레이어별 COST 획득 |
| 3. 행동 순서 | 이번 턴 필드 유닛의 Speed 순서 결정 |
| 4. 예약 | 사용자·행동·대상·실행 순서를 확정, 공유 자원 확보 |
| 5. 실행 | 행동 직전 조건 재판정 → 예약 순서 실행 → 해당 유닛 턴 종료 |

Speed 변화는 아직 차례를 시작하지 않은 유닛에 반영한다. 현재 행동권 소유 유닛은 턴 종료까지 계속하며 다른 유닛이 끼어들지 않는다. 속도 변화가 추가 차례를 만들지 않는다.

## 예약과 자원

| 구분 | 행동 | 횟수/조건 |
| --- | --- | --- |
| 메인 | 일반 스킬, 도주, 배치·교체 | 기본 1회 |
| 서브 | 이동, 아이템, 서포트 요청 | 유닛별 기본 횟수(통상 1, 일부 2) |
| 독립 | EX스킬 | 메인·서브·행동권 미소모, 플레이어별 턴당 사용 1회/예약 1개 |
| 마무리 | 턴 종료 | 예약 마지막, 차례를 마치며 행동권 소모 |

- 서브와 EX는 **메인 이전 구간**에 배치한다. 메인을 생략해도 사용할 수 있지만 `메인 → 서브`는 불가다.
- 4단계 확정 이후 실행 중 다른 행동으로 바꾸지 않는다. 상대의 예약 스킬/대상은 공개하지 않는다.
- 공유 자원은 예약 시 확보하고 실제 소비는 실행 결과로 판정한다. 실행 직전에 필드 잔류·상태·대상·사거리·자원을 다시 확인한다.
- 실패/무효인 메인·서브도 해당 행동 횟수 1회를 소모한다. 실패 하나로 다음 예약을 자동 취소하지 않는다. 상태 이상은 메인/서브/EX 중 무엇을 막는지 개별 확인한다.
- 추가 서브 횟수 효과는 획득한 턴에 쓸 수 없다. 다음 초기화에서 지속 시간이 감소한 뒤 남아 있어야 하므로 부여 지속 시간은 2턴 이상이다. 미사용 횟수는 이월하지 않는다. 예약 후 효과가 해제되면 해당 효과로 확보한 미실행 추가 예약을 취소한다.

| 스킬 결과 | COST | EX 공용 사용 횟수 | BP |
| --- | --- | --- | --- |
| 실행 조건 불충족으로 무효/취소 | 미소비 | 미소비 | 해당 비용 소비 |
| 실행 후 명중 실패/부가 효과만 실패 | 정상 소비 | EX라면 소비 | 정상 소비 |
| 정상 실행 | 정상 소비 | EX라면 소비 | 정상 소비 |

해당 자원을 쓰는 기술에만 적용한다. 일반 스킬은 사용당 BP 1이며 부족한 BP를 음수로 차감하지 않는다. 아이템 실패 시 수량은 보존하고, 서포트 실패 시 새 쿨다운은 시작하지 않는다. 요청에 쓴 서브 횟수는 소모한다.

## 스킬·속성·피해

일반 스킬은 유닛당 최대 4개, BP는 스킬별로 관리한다. **Trait(속성)**과 **Type(변화/태크 Tech/신비 Mystic)**를 분리한다. 유닛은 최대 두 Trait를 가진다. 구표기 수/열/뢰는 습/염/전이다.

| 공격 Trait | 강세 2배 | 약세 0.5배 |
| --- | --- | --- |
| 염 | 전·금 | 습·폭 |
| 습 | 염·폭 | 전·신 |
| 전 | 습·신 | 염·금 |
| 폭 | 금·염 | 습·신 |
| 금 | 신·전 | 염·폭 |
| 신 | 폭·습 | 전·금 |
| 성 | 암·사 | 순 |
| 암 | 성·사 | 순 |
| 순 | 성·암·무 | 염·습·전·폭·금·신·사 |
| 사 | 순 | 성·암 |
| 무 | 없음 | 없음 |

표에 없는 상성은 1배. 역방향 상성을 일괄 생성하지 않는다. 특히 성↔암은 양방향 2배, 순→무는 2배지만 무→순은 1배다. 염·습·전·폭·금·신→순은 1배다.

```text
기본 피해 = (해당 공격력 / max(해당 방어력, 1)) × 스킬 데미지 배율
적용 상성 = clamp(대상의 각 속성에 대한 배율의 곱, 0.5, 2)
최종 피해 = ceil(기본 피해 × 적용 상성 × 자속 보정)
```

태크는 TAtk/TDef, 신비는 MAtk/MDef를 쓴다. 자속 보정은 유닛의 속성 중 하나와 스킬 속성이 같으면 1.5배이며 중복 적용하지 않는다. 상성 제한 뒤 자속을 곱하고 최종 한 번만 올림한다. 실제 방어력 값을 1로 고치지 않는다. 정확히 0인 피해는 0이다.

광역 피해는 같은 공격 직전 상태로 대상별 계산 후 함께 적용한다. 다단은 한 타격이 빗나가면 이후 타격을 취소하고 이미 적용한 결과는 유지한다. 사용자 퇴각 시 미실행 타격을 취소하지만 마지막 적의 퇴각만으로 중단하지 않는다. 나머지 세부 순서는 원문/미정 목록을 따른다.

### BP 부족과 헤일로 이상

예약 **확정 시점**에 원래 스킬의 BP가 0이었는지 기록한다. 실행 시에도 부족하면 헤일로 이상으로 대체하고, 실행 전에 회복되었다면 원래 스킬을 실행한다. 확정 시 BP가 있었으나 실행 시 부족해진 경우에는 원래 스킬을 취소한다. 다른 행동 금지 조건을 무시하는 예외가 아니다.

헤일로 이상: 무/신비, 자신의 슬롯 중심(사거리 0), 위력 50, 명중 80%, 범위 -1~1, BP 40. 최대 HP의 55% 소모 및 **헤일로 이상 자체 BP** 완충이며 원래 스킬 BP 회복이 아니다. HP 1 생존을 보장하지 않는다.

2026-10-02 [D-007](DECISIONS.md) 확정: 퇴각·행동 금지 검사 → BP 0 대체 결정(원래 대상·사거리 검사 생략) → 범위 피해 → 명중 여부와 무관하게 `ceil(최대 HP × 0.55)` 소모·자체 BP 완충 → 모든 후속 처리 후 승패 판정. 범위 피해로 시전자가 퇴각하더라도 필수 후속 처리를 마친다. 슬롯 범위 공격이므로 자신·아군도 범위에 포함하며, 대상별 피해는 동일한 공격 직전 상태에서 계산한다.

## 타깃·이동·배치

- 유닛 지정은 같은 유닛을 추적하고 실행 시 사거리를 재확인한다. 대상 퇴각 시 취소한다. 교체 후 지정 승계는 미정이다.
- 슬롯 지정은 원래 슬롯을 유지하며 피아식별 없이 그 슬롯의 유닛에 적용한다. 빈 슬롯에는 유닛 효과가 없다.
- 거리 = 슬롯 번호 차이의 절댓값. 최소·최대 사거리는 양 끝을 포함한다. 효과 범위는 1~9번 슬롯 경계에서 잘라 적용한다.
- 자발적 이동은 서브 1회. 아군은 이동 경로 순서대로 위치를 교환하고 적은 통과할 수 없다. 예약 후 적에게 막히면 적 전까지 이동한다.
- 자발적 이동 시도 종료마다 성공/실패와 무관하게 **이동 불가 2회**를 받는다. 그 차례의 턴 종료부터 1 감소하므로 다음 차례 이동 불가, 그다음 차례 이동 가능이다. 교환 상대나 강제 이동 유닛에는 이 이유만으로 부여하지 않는다.
- **D-009 예외(2026-10-04):** 실행 시 이미 이동 불가 또는 외부 이동 금지 상태여서 막힌 시도는 이동 불가를 새로 부여/갱신하지 않는다. 기존 횟수는 유지하며, 서브 1회 소비와 자기 종료 시 1회 감소는 그대로 적용한다. 경로 차단 등 다른 실패의 2회 부여는 유지한다.
- 표시 요구 D-008: 4단계 아군 이동 미리보기는 실제 전투 상태와 분리한다. 5단계 시작 시 예시 이미지를 제거하고 실제 좌표에서 예약 행동을 실행한다. 적의 비공개 예약은 예측에 포함하지 않는다. [검토 기록](reviews/2026-10-02-movement.md).
- 배치·교체는 메인 1회, 정상 실행 시 COST 1. 새 출전 유닛은 이번 턴의 차례/예약을 승계하지 않고 다음 턴부터 순서에 포함한다. 배치·교체 뒤 서브 행동은 불가다.
- 대기 중에는 버프·디버프 진행이 정지하며 이동 불가 잔여 횟수도 보존한다. 서포트 쿨다운은 계속 감소한다.

## EX·서포트·아이템·도주

- EX는 자기/다른 아군 필드 유닛의 메인 이전 구간에 사전 예약한다. 자신의 차례 전에도 가능하며 메인 생략/무효만으로 금지하지 않는다. 사용자는 필드에 있어야 하고 상대 차례에는 예약할 수 없다.
- A의 차례에 B의 EX를 실행하면 행동권 소유자는 A, 실제 사용자는 B다. 공격력·속성·위치·반동·‘자신’ 효과와 처치 주체는 B 기준이다.
- 서포트는 대기 유닛의 고유 스킬을 현재 아군 필드 유닛의 서브 1회로 요청한다. 플레이어별 턴 횟수 제한은 없으며 개별 쿨다운/자원/서브 횟수를 확인한다.
- 아이템은 현재 아군 필드 유닛의 서브 1회와 플레이어별 턴당 1회 한도를 따른다. 모리모리 군은 화상 치료(BP 회복 없음), 요괴 MAX는 대상의 모든 스킬 현재 BP를 각 최대치까지 회복한다.
- 야생 전투 도주는 메인 1회. 확률은 `clamp((아군 평균 Speed / 적 평균 Speed + 아군 평균 레벨 - 적 평균 레벨) × 0.8, 0.1, 1)`이다. 현재 필드 유닛만 평균에 포함하며 적 평균 Speed가 0이면 100%다. 성공 시 현재 상태 그대로 전투 종료, 재화 환급/롤백은 없다.

## 퇴각과 종료

HP≤0이면 즉시 퇴각한다. 필드 전멸은 대기 유닛이 있어도 패배지만, 공격의 반동 등 필수 후속 효과까지 처리한 묶음으로 승패를 확정한다. 쓰러진 대상은 반격할 수 없고 반격에 다시 반격하지 않는다.

지속 피해는 동시에 적용한 결과로 승패를 판정한다. 종료 확정 시 뒤의 초기화/예약을 중단한다. 다세력 전투에서 한 세력만 생존하면 그 세력이 승리하고, 여러 세력이 남으면 패배 세력의 행동만 제거하고 계속한다. 이미 부여된 디버프는 고유 종료 규칙을 따른다. 모든 세력이 함께 전멸하면 아래 PvP/PvE 규칙을 적용한다.

PvP 동시 전멸은 마지막 **행동권 소유 유닛**의 소유자 승리다. 실제 EX/서포트 사용자 기준이 아니다. 아무도 행동하지 않았다면 플레이어 1이 패배한다. PvE에서 플레이어가 포함된 동시 전멸은 항상 플레이어 패배다.
