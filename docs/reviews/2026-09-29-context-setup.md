날짜: 2026-09-29 · 상태: **검토 대기** · 검토자: **dayoff53**

## 목적과 관련 결정

CounterAchive를 마세이 키보토스로 전환하는 목표와 전투 규칙을 저장소 안에 남기고, Codex가 기능 구축을 주도한 뒤 dayoff53이 결과를 검토할 수 있는 작업 환경을 구성한다. [D-001~D-003](../DECISIONS.md)이 기준이다.

채팅 첨부와 과거 대화에 의존하던 기준을 저장소 안에서 찾을 수 있게 했다. 루트 지침은 필요한 작업별 문서로 안내한다. 전투 규칙 요약은 원문을 대체하지 않으며 미정 사항은 확정 규칙과 구분했다.

## 검증

아래는 이번 작업에서 수행한 검사 결과다.

- 첨부와 보존본 SHA-256 동일: `96F203868C9BF8259B9EA47748FBDA92075AD6E6358C5A598C6AFFA0891AD9E5`.
- 규칙 원문 1,702행 및 20개 절 확인. 요약과 미정 목록을 원문에 대조.
- Markdown 문서 9개의 로컬 링크 86개 확인: 깨진 링크 없음. 루트 `AGENTS.md`는 4,398바이트.
- 기존 변경/미추적 씬·프리팹 5개 파일의 작업 전후 SHA-256 동일: 사용자 변경 보존 확인.
- 규칙/환경 문서 교차 검토 완료. 지속 피해의 동시 처리 범위, 다세력 승리 조건, 기존 유닛 선택 분기를 보완함.
- Unity 테스트 명령의 `runTests`, `testPlatform`, `testResults`와 `quit` 생략을 로컬 Test Framework 1.7.0 소스에 대조함. 실제 테스트 실행 결과를 뜻하지 않음.
- 변경 문서의 공백 검사와 `git diff --check` 통과.
- Unity 에디터/Hub 실행 파일 존재 확인. 에디터 업그레이드/패키지 설치/전역 설정 변경 없음.
- Unity 컴파일·Play Mode·게임 빌드·별도 새 Codex 세션의 지침 자동 로딩: 이번 문서 구성에서 실행하지 않음.

## dayoff53 확인 순서

1. [프로젝트 기준](../PROJECT.md)에서 프로젝트 목표와 Codex/dayoff53 역할 분담을 확인한다.
2. [규칙 안내](../BATTLE_RULES.md)에서 원문 기준일과 확정 규칙의 방향을 확인한다.
3. [미정 목록](../DECISIONS.md)을 확인한다. 모든 항목에 지금 답할 필요는 없으며 해당 기능 구현 때 구체적으로 다룬다.
4. [전환 계획](../ROADMAP.md)에서 첫 구현 작업이 전투 기반/데이터 정리라는 점을 확인한다.

## 남은 사항

새 전투의 구현과 실제 Unity 동작 검증은 다음 작업이다. 기존 AP 기반 전투와 Speed 기반 새 규칙의 차이를 정리했으며, 새 규칙을 구현 완료로 표시하지 않았다. 기존 사용자 씬/프리팹 변경은 보존한다. Unity 제품명은 아직 `CounterAchive`다.
