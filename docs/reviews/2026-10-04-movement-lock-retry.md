# 이동 금지 중 재시도: 디버프 연장 방지

2026-10-04 / 상태: **검토 대기** / 검토자: dayoff53

## 변경

사용자 요청을 [D-009](../DECISIONS.md)에 확정 결정으로 기록했다. 원문 14절의 실패 페널티 중 **이미 이동 금지 상태여서 실행하지 못한 경우**에만 예외를 적용한다.

- 이동 불가 1회 중 재시도: 좌표는 유지, 서브 1회 소비, 이동 불가 **1회 유지**. 자기 종료에서 0회로 해제된다.
- 같은 차례의 첫 이동으로 2회를 얻은 뒤 추가 시도: **2회 유지**, 재부여하지 않는다.
- 외부 이동 금지만 있는 상태에서 실패: 별도의 이동 불가 2회를 새로 만들지 않는다. 외부 금지가 해제되면 남은 예약은 현재 조건에 따라 실행한다.
- 정상 이동 및 이동 금지와 무관한 경로 차단/거리 실패: 기존대로 2회를 부여한다. 교환 상대에는 부여하지 않는다.

`TurnBattle.Movement.cs`에서 이동 금지 원인을 먼저 구분하고 `FinishMovement`에 재부여 생략 여부를 전달한다. 복사본 미리보기도 같은 예외를 적용한다. 로그와 이동 창 안내에도 갱신하지 않음을 표시한다. 예약 자체를 금지하거나 기존 상태를 즉시 해제하는 변경은 아니다.

## 검증

- Unity `6000.5.10f1` 사본에서 컴파일 성공, **EditMode 67/67**, **PlayMode 8/8 통과**.
- 잔여 1회 중 두 번 재시도 → 횟수 유지 → 메인 스킬 → 자기 종료에서 해제 → 다음 턴 정상 이동을 검사했다. 외부 금지 중 새 디버프가 생기지 않고 해제 후 남은 이동이 실행되는 경우도 포함한다.
- 실제 Stage_Battle 버튼으로 A→4번 실행 후 다음 턴 금지 중 A→5번 재시도, 잔여 유지 로그, 종료 후 해제와 다음 턴 이동을 확인했다. 기존 경로 차단/부분 이동/교환 테스트도 통과했다.
- 증거: `Logs/movement-lock-editmode.xml`, `Logs/movement-lock-playmode.xml` 및 대응 로그. [결과 요약](evidence/2026-10-04-movement-lock-tests.json).
- 마키보 파일 59개와 Stage_Battle 씬은 검증 사본과 해시 일치. 원본 씬/리소스는 변경하지 않았다. 변경 코드/문서의 공백 검사는 통과했다.
- 원본 에디터 직접 조작과 플레이어 빌드는 미실행이다. 기존 사본의 PlayerSettings 자동 이행 차이와 Odin 초기화 예외/Missing Script 경고는 별도 미해결 항목이다.

## 확인 순서

1. Stage_Battle에서 A→4번만 예약하고 턴을 넘긴다.
2. 다음 턴 A의 이동 불가가 1회인 상태에서 A→5번을 예약한다.
3. 예약 확정 → A 차례 시작 → 이동 시도. A는 4번에 있고 로그에 `이동 불가 재부여 없음 (잔여 1회)`가 표시된다.
4. A의 턴 종료 후 이동 불가는 0회다. 다음 턴 A→5번을 예약하면 정상 이동한다.

실패한 시도의 서브 소비, 메인 스킬 후속 실행, 자기 종료의 횟수 감소는 유지한다. 기존 사용자 변경과 비스크립트 리소스는 보존한다.
